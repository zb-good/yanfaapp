# 建筑防渗漏智能评估 App

一个原生 Android 静态展示 Demo，用于演示建筑防渗漏专利流程移动端功能。

当前版本覆盖：

- S1 标准化建筑防渗漏数据采集
- S2 建筑渗漏风险聚类评估
- S3 建筑渗漏全工况演化预测
- S4 匹配式初始防渗漏维修策略生成
- S5 建筑防渗漏维修策略智能优化

页面中的建筑档案、风险等级、预测结果、策略库、优化参数均为静态示例数据，适合用于产品原型演示和 CI 打包验证。

## 运行方式

1. 用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成。
3. 选择模拟器或真机，点击 Run。

当前工程使用 Java 和传统 Android View，不依赖第三方库。
